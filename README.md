# rantegraph/.github

This repository holds the public profile and the default community files of the
[rantegraph](https://github.com/rantegraph) organization on GitHub.

| Path | What it is |
|---|---|
| [`profile/README.md`](profile/README.md) | The README on the organization's GitHub page. |
| [`images/`](images) | Images the profile uses. |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | The code of conduct for every Rante repository. |
| [`SECURITY.md`](SECURITY.md) | How to report a security vulnerability. |

A repository's own files take precedence over the defaults here.

Learn more about Rante Graph at [developer.rante.com](https://developer.rante.com/graph), and about Rante's open-source
projects at [opensource.rante.com](https://opensource.rante.com).
