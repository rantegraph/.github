# Code of conduct

Rante's open-source projects adopt the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

It applies in every space of a Rante project: issues, pull requests, discussions, and anywhere else people take part in
it.

Report unacceptable behavior to [opensource@rante.com](mailto:opensource@rante.com).
